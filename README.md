# Project-13---Debugging-Practice

This is a beginner Python project built as part of my 100 Days of Code challenge.

The goal of this project is to practice debugging skills by identifying, reproducing, and fixing common programming errors.

**Project Overview**

This Debugging Practice project covers:

Logic errors

Off-by-one errors

Missing imports

Input validation issues

Edge case handling

Understanding program flow

Instead of building one large program, this project focuses on thinking like a debugger.

**Why this project exists**

Debugging is one of the most important skills in programming.

This project helped me slow down, read code carefully, and understand why something doesn’t work, not just how to fix it.

It taught me to approach problems methodically instead of guessing.

**What I learned**

How to describe a bug before fixing it

How to reproduce bugs consistently

How to identify logic errors vs syntax errors

How to use print statements to trace values

How to handle user input safely

How to reason about loops and conditions

**How the code works (step-by-step)**

Each section presents a buggy or incomplete example

Comments explain what the bug is and why it occurs

A corrected version is provided for comparison

Examples increase in complexity

Final examples reinforce correct logic
